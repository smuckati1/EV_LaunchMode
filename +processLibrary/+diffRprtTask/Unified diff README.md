# Unified Simulink® Model Diff Report

This tool generates a **custom model difference report** for Simulink models.  
It compares the current version of the model vs. previous commit of the model and generaetes:

- A unified top-level view of all the differences as a table, and
- Hyperlinks to two model web views so you can investigate the changes.
    

## Typical Use Case
- Automatically create diff reports when a **pull request** is opened, making design reviews easier (no need to open Simulink).
